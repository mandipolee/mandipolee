About PhishGuard

A phishing URL detector built as a portfolio project by Mandip Oli.

PhishGuard scores any URL from 0 to 100 using an advanced 25+ signal heuristic engine: brand impersonation detection (40+ protected brands), homoglyph and Cyrillic look-alike characters, punycode/IDN homograph attacks, typosquatting patterns, credential-harvesting path analysis, suspicious subdomains, high-entropy generated domains, URL shortener abuse, suspicious query parameters, non-standard ports, and known phishing-kit patterns — with weighted scoring, four verdict tiers, and per-signal explanations.
